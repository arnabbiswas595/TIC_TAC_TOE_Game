# TIC_TAC_TOE

A console-based **Tic Tac Toe Game** built to test and consolidate my **C programming** skills acquired in the **CSE-1201** course. This hands-on project bridges classroom learning with real application.

---

## Project Description

An interactive **C-based** terminal application that adds a competitive twist to the classic **Tic-Tac-Toe** challenge. Players take turns strategic placing their marks (**X** and **O**) on a **3x3** grid while receiving instant updates on board status, turn detection, and win or draw conditions after each move.

---

## Features

- **3x3** Dynamic Grid Display
- **Two-Players** Mode
- Clean Terminal UI

---

## Concept Used

The following C programming concepts were used in this project:

- Dual Game Modes
- Custom Player Profiles
- Vibrant ANSI Color UI
- Performance Summary

---

## Game Rules

- Game is played on a 3x3 grid.
- Player 1 gets 'X' and Player 2 gets 'O'.
- Take turns to choose a box from 1 to 9.
- First to align 3 marks in a row/column/diagonal WINS!

## How to Run

Compile the program:

```
gcc main.c -o tictactoe
```

Run the program:

```
./tictactoe
```
